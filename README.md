# Visual Share 视觉分享
This is a mod for sharing visual information in-game\
这是一个用于游戏内分享可视化信息的mod

# Functions 功能

## Image Share 图片分享
- Share the current game screen within the game\
  在游戏内分享当前游戏画面
- Simple modifications can be made on the image\
  可在图片上进行简单的修改

## Drawing board 画板
- Freely draw on the board and show it to others\
在画板上自由绘画并展示给他人

## Misc 杂项
- Display information about items inside the backpack\
  展示背包内物品信息
- Display inventory contents\
  展示物品栏内容
- Display the contents of the Ender Box\
  展示末影箱内容
